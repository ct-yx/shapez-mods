# Auto Tunnels

> 方向锁定铺传送带时，自动在合适的位置用地下传送带跨越既有物流。

- **分类：**建造
- **版本：**1.1.0
- **文件：**[`auto-tunnels@1.0.4.js`](../../mods/auto-tunnels%401.0.4.js)

## 用途

Auto Tunnels 扩展的是传送带方向锁定铺设逻辑。当路线紧邻一段连续障碍且后方有空出口时，它会检查当前实际可用距离并尝试放置一对地下传送带，而不是单纯中断铺设。

## 核心功能

- 仅接管普通传送带的方向锁定批量铺设；其他建筑保留原版拖动建造逻辑。
- 实时读取游戏的地下传送带范围数组；自动适配 Belt Speed Control 的范围倍率，以及新增的三级、四级地下传送带。
- 按实际距离选择可用且足够短的等级；范围设置改变后无需重启此 Mod。
- 使用局部坐标判断接收槽，兼容旋转后的原版平衡器和 4 / 5 / 8 / 10 / 16 路平衡器。
- 只跨越紧邻的一段连续障碍，并在第一处空出口结束；遇到任意既有地下传送带、正常前向传送带或可直接接收物品的机器时保留常规连接，避免嵌套和误跳跃。

## 使用方法

1. 选择普通传送带并使用方向锁定铺设。
2. 让路径在障碍前至少保留一格传送带，并在障碍后留出第一格空位作为出口。
3. 启用 Belt Speed Control 后，Auto Tunnels 会自动读取各级隧道的当前长度；三级、四级会在可用时参与选择。

## 兼容性与注意事项

- 本地版本基于 Auto Tunnels Remake 重写了选距和连接判断；若与其他会改写方向锁定铺设的 Mod 同用，请优先在测试存档检查组合效果。
