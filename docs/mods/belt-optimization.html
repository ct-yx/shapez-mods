Belt Optimization

独立控制传送带动画冻结和低缩放物品简化，不改变物流模拟。

版本 1.0.0文件 belt-optimization.jsshapez.io 1.x

用途

这个 Mod 只改变传送带的绘制方式，不改变传送带速度、物品移动、地下带连接或存档数据。可以单独启用，也可以和 Belt Speed Control 组合。

核心功能

  • 传送带箭头和底纹在超过吞吐阈值后固定到静态帧。
  • 低缩放时每条传送带路径只绘制首尾物品。
  • 低缩放时使用无动态箭头的静态传送带底图。
  • 物品逻辑、传送带吞吐和机器处理继续运行。
  • 所有开关和阈值注册在 Structured Mod Settings 的「游戏模组（MODS）」页面。

默认设置

设置默认值
启用传送带视觉优化开启
动画冻结吞吐阈值15 items/s
低缩放物品简化开启
简化渲染缩放阈值0.5×

使用方法

  • 同时启用 structured-mod-settings.js，打开「设置 → 游戏模组（MODS）→ 传送带优化」。
  • 总开关控制两类视觉优化；动画阈值设为 0 可关闭动画冻结。
  • 低缩放物品简化可以单独关闭，并可调整触发缩放阈值。

兼容性与注意事项

与 Belt Speed Control 组合时，物流倍率和视觉优化分别生效。Zoom out before Mapmode 只负责地图总览缩放。

获取方式

下载整合包后，只需将本 Mod 对应的 JS 文件复制到游戏 Mod 目录。
