Factory Area Snapshot

自动识别机器范围或在地图总览框选区域，以 25–64 个比例自适应分区导出高分辨率 PNG。

版本 1.6.0文件 factory-area-screenshot.jsshapez.io 1.x

不是地图总览截图

该 Mod 不使用地图总览的剪影样式，也不依赖世界预览框。它以普通镜头的顺序渲染地图背景、传送带物品、建筑前景和 Hub，所以导出效果与游戏中的常规工厂画面一致。

范围、留白与地图框选

默认截图范围来自普通层中已放置机器的最小外接矩形。默认在上下左右各增加 4 格留白，可调整为 0–32 格；这让最外侧建筑不会贴着画面边缘，也能包含边界附近的传送带与地下带出口。需要任意局部截图时，点击「选择地图区域」，缩小进入地图总览后用左键拖拽矩形；此模式严格按框选格子导出，不额外添加机器范围留白。

分区渲染与拼接

  • 导出会按最终图片横竖比划分 25–64 个逻辑捕获分区。接近方形的图片优先使用 25、36、49 或 64 个分区；超宽或超高图片会在对应档位内微调数量和横/竖分区数，不拉伸画面。较小图片使用最终画布拼接；达到 96 MP、或任一边超过 16384 px 时，自动改用条带缓存和流式 PNG 编码，不再常驻整张最终 Canvas。
  • 默认开启清晰像素采样。最终倍率高于 1× 时，分区先以原生清晰源倍率走普通镜头绘制，再由 GPU-preferred Canvas 2D 以最近邻合成到最终尺寸，避免游戏内部平滑路径放大同一精灵后变糊。
  • 每个分区四周额外绘制缓冲边缘，再只拼接核心部分，避免大型建筑和物品跨分区时产生接缝或截断。
  • 默认暂停模拟，确保所有分区来自同一时刻；结束、报错或取消时会恢复原先速度与图层。
  • 左上角独立「截图」按钮展开控制面板，不占用原版物品栏或工具栏；地图总览仅用于框选范围，最终 PNG 始终使用普通工厂层渲染。

分辨率和内存保护

  • 只需选择目标分辨率；Mod 会依据当前截图面积自动计算渲染倍率。
  • 目标分辨率可选 16–1024 MP，默认 64 MP；提供 384、512、768、1024 MP 超高分辨率档位。选择值直接决定总输出像素，避免倍率与预算互相压缩成相同结果。支持流式编码时，单边最高 65535 px。
  • 分析面板会显示自动计算后的倍率与最终输出尺寸；它们用于确认结果，不是额外的质量控制项。
  • 可关闭传送带动态物品，优先导出静态、清晰的工厂布局图。

使用流程

  1. 进入存档后点击左上角「截图」。
  2. 点击「机器范围」自动分析机器边界，或点击「选择地图区域」后缩小进入地图总览并左键拖拽矩形。
  3. 检查分析得到的范围、输出尺寸、“清晰源 / 最终倍率”与“分区捕获”；按需要调整目标分辨率。
  4. 点击「导出 PNG」；浏览器会下载带时间戳的图片文件。
64 MP 以下的 RGBA 最终画布约占用 256 MB。实际输出达到 96 MP、或任一边超过 16384 px 时，支持流式压缩的运行环境会改用“按宽度动态限制的条带 + 单个渲染块”的工作缓存；分区绘制与最近邻合成使用 GPU-preferred Canvas 2D，PNG 编码时才复制到独立 CPU 读回画布。PNG 压缩和文件写出仍由 CPU 完成。游戏地图 API 共享 Canvas 2D 绘制状态，所以地图绘制保持串行以确保结果正确。

设置与兼容性

左上角面板可独立使用；若同时启用 Structured Mod Settings UI，同样的选项会出现在「设置 → 游戏模组（MODS）」中。Mod 不改变机器、物流或存档数据，且不会改变当前相机位置、缩放或地图总览范围。

获取方式

下载整合包后，将本 Mod 的 JS 文件复制到游戏 Mod 目录。
