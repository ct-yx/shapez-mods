# Factory Area Snapshot / 工厂区域截图

> 使用普通镜头渲染导出工厂或地图总览选区。游戏内只保留质量、选区大小和两个截图按钮；详细配置统一放入模组设置。

- **分类：**视图 / 工具
- **版本：**2.0.0
- **文件：**[`factory-area-screenshot.js`](../../mods/factory-area-screenshot.js)

## 游戏内快速面板

左上角「截图」按钮展开后只显示：

1. **质量：**低 / 中 / 高；每档显示当前在设置中配置的 MP 值。
2. **地图选区：**当前选区的 `宽 × 高` 格数；尚未框选时显示“尚未选择”。
3. **选区截图：**进入地图总览后左键拖拽选区，松开后立即按当前质量导出。
4. **整地图截图：**按设置中的整地图默认质量与留白，自动检测已放置机器范围并导出。

普通状态不再显示输出尺寸、渲染倍率、分区数量、像素采样、动态物品等技术信息。截图或框选期间才显示必要的状态与取消按钮。

## 选区质量规则

| 质量 | 默认分辨率 | 选区上限 | 自动行为 |
| --- | ---: | ---: | --- |
| 低 | 16 MP | 48 × 48 格 | 超出后低质量锁定，自动使用中质量。 |
| 中 | 48 MP | 128 × 128 格 | 超出后低/中质量锁定，自动使用高质量。 |
| 高 | 256 MP | 1024 × 1024 格 | 超出后显示“可能不够清晰”的确认提示。 |

三个 MP 值均可在 **设置 → 游戏模组（MODS）→ 工厂区域截图** 中自由修改；修改数值本身不触发选区警告，选区限制始终按格子尺寸判断。当前默认值是 16 / 48 / 256 MP，最高设置值可到 1024 MP。

## 整地图默认值

整地图截图默认使用：

- **高质量**
- **10 格外围留白**

两项均可在模组设置修改。整地图模式只读取普通层已放置机器的实际边界，再四边同时添加留白；地图总览只用于选区，最终 PNG 一律走普通镜头渲染路径。

## 设置页面

启用 `structured-mod-settings.js` 后，以下项目会注册在原版风格的 **设置 → 游戏模组（MODS）** 页面：

- 整地图默认质量
- 整地图外围留白
- 低 / 中 / 高三档 MP 值
- 清晰像素采样
- 是否绘制传送带上的动态物品
- 截图期间暂停模拟

## 性能与兼容性

- 实际输出达到 96 MP、或单边超过 16384 px 时，自动使用条带缓存和流式 PNG 编码，避免常驻完整最终画布。
- 地图绘制和最终合成使用 GPU-preferred Canvas 2D；PNG 像素读回、压缩与文件写出由浏览器处理。
- 截图默认暂停模拟并在完成、取消或出错后恢复原速度与图层。
- 清晰像素采样默认开启：先用最高 1× 的可用源倍率绘制，再以最近邻方式合成到目标分辨率，减少重复放大游戏精灵图集带来的模糊。
- 内部使用约 2048 px 的工作分块和 48 px 缓冲边缘；它们只是内存与接缝控制，不会改变最终 PNG 的尺寸。
- 最大输出边长支持到 65535 px（由浏览器和设备内存决定实际可用范围）。
- 不修改物流、建筑属性或存档数据，`doesNotAffectSavegame: true`。
