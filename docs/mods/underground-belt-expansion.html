Underground Belt Expansion

增加三级、四级地下传送带，并独立配置各等级连接距离。

版本 1.0.0文件 underground-belt-expansion.jsshapez.io 1.x

核心功能

  • 在原版地下传送带基础上增加三级、四级变形体。
  • 三级、四级复用二级地下带贴图和连接行为。
  • 四个等级的连接距离可以分别设置为基础范围的 1–10×。
  • 修改距离后刷新既有地下带连接缓存。
  • 不修改普通传送带速度、平衡器速度或读取器行为。

基础距离

等级基础距离
一级5 格
二级9 格
三级13 格
四级17 格

使用方法

  • 同时启用 structured-mod-settings.js，在「设置 → 游戏模组（MODS）→ 地下传送带扩展」中修改四档距离倍率。
  • 启用 auto-tunnels@1.0.4.js 时，自动铺带会读取当前等级和实时距离。
  • 从旧版 Belt Speed Control 拆出的地下带距离设置会在首次注册时自动迁移。

组合关系

启用 Belt Speed Control 时，速度倍率和地下带扩展可以叠加；两者的设置分别保存。

获取方式

下载整合包后，只需将本 Mod 对应的 JS 文件复制到游戏 Mod 目录。
