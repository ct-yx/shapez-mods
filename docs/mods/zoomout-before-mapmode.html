Zoom out before Mapmode

扩大进入地图总览前的缩放范围。

版本 1.6.0文件 zoomout-before-mapmode.jsshapez.io 1.x

用途

这个 Mod 面向大工厂规划：可以在进入地图总览之前看得更远。

核心功能

  • 进入地图总览前的缩小范围可设置为原版的 1–8×，默认 2×。

使用方法

  • 启用 Structured Mod Settings UI 后，在「地图总览缩放」卡片中调整范围。
  • 如果只想恢复原版地图范围，将预览范围设置为 1×。

实机截图

兼容性与注意事项

该 Mod 不改变普通建造镜头的最小缩放限制，只调整进入地图总览前的阈值。传送带视觉优化由 Belt Optimization 独立负责。

获取方式

下载整合包后，只需将本 Mod 对应的 JS 文件复制到游戏 Mod 目录。
